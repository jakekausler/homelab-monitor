Implements hourly periodic reconciliation of Karma silence outcomes back into the
`alert_outcomes` table, closing the feedback loop for stateless Karma-driven silence
decisions. Adds new reconciler collector, silences HTTP client, database uniqueness
constraint, and idempotence fix for outcome insertion.

  `KarmaOutcomeReconciler` collector; periodic hourly tick; fetches active silences

  outcomes to repository with idempotent `INSERT ... ON CONFLICT DO NOTHING`

**Design decisions:**

- Reconciler runs hourly (CRON `0 * * * *`), aligns with Alertmanager silence UI
  polling cadence; not real-time (acceptable for user-facing decisions).
- Outcome sourced from silence `comment` field (structured as `{"decided_by": "admin",
  "reason": "..."}`) — matches STAGE-010-002 Refinement findings.
- Idempotent UNIQUE constraint prevents double-writes; ON CONFLICT DO NOTHING is
  silent (no error), matches auto-fix safety model preference for fail-safe patterns.
- `decided_by` TEXT not INT (accommodates future non-user sources: systems, CI, etc.).
