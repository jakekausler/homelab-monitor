## Backend
- New `POST /api/runbooks/{runbook_id}/trigger` endpoint: operator-initiated manual trigger with body `{mode: 'dry_run' | 'real'}`. Honors all seven autofix non-negotiables (allow-list, rate-limit, cooldown, kill-switch, risky→dry-run+approval, audit, identity). Returns 400 `dry_run_required_for_risky`, 404 `runbook_not_found`, 409 `kill_switch` / `rate_limit` / `cooldown` / `already_running` / `runbook_disabled`.
- New `Orchestrator.handle_operator_trigger(runbook_id, mode, *, principal, ip)` — skips MATCH, skips `auto_trigger` allow-list check (operator explicitly chose the runbook), but enforces every other gate. Refactored `_check_operational_gates` to accept `require_auto_trigger: bool = True`.
- Widened `_claim_and_exec`, `_claim_and_store_dry`, `_exec_claude`, `_write_exec_log`, `_process_feedback`, `_maintenance_window`, and `_persist_outcome` to accept `alert: Alert | None`. Threaded `principal` and `initiated_by` through the entire persistence + audit path.
- Migration `0050_add_runbook_runs_initiated_by.py` — adds `initiated_by TEXT NOT NULL` column to `runbook_runs`, backfilling existing rows to `'alert'`. Migration uses two separate `batch_alter_table` blocks (add-with-default then drop-default) since SQLite batch mode uses the FINAL column schema for the row-copy step.
- Defense-in-depth on `PATCH /api/runbooks/{runbook_id}`: rejects `auto_trigger=true` when `risk_tag='risky'` with 400 `risky_auto_trigger_denied` (mirrors the frontend info-tooltip semantic).
- Router bug fix: `user` was annotated as `str` but `require_session()` returns `User` — corrected to `user: Annotated[User, ...]` and audit uses `user.username`.
- Audit trail: `runbook_runs.initiated_by='operator'` on operator-triggered rows; `who=<principal>` in `autofix.ran`, `autofix.dry_run_stored`, `autofix.denied`, `autofix.trigger_rejected`; `ip=<client-ip>` captured for forensic reconstruction. `homelab-fixer` OS-user identity for exec is UNCHANGED (non-negotiable #3 — principal is for audit only, never for `sudo -u`).
- New exception types `RunbookNotFoundError` and `DryRunRequiredForRiskyError` (raised by orchestrator, mapped to HTTP status by router).
